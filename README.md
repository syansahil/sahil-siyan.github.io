# Sahil Siyan Portfolio

A simple responsive portfolio website for Sahil Siyan.

## Files

index.html
Sahil_Siyan_Resume.pdf

## Run locally

Open index.html in a browser.

## Deploy with GitHub Pages

1. Create a new GitHub repository.
2. Upload index.html and Sahil_Siyan_Resume.pdf.
3. Open Settings > Pages.
4. Select the main branch as the source.
5. Save and wait for GitHub Pages to publish the site.

## Deploy with Vercel

1. Create a new Vercel project.
2. Import the GitHub repository.
3. Deploy.
4. No build command is required because this is a static HTML site.
